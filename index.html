为什么 Windows 显存填一半算力不仅没少，反而一样？

Linux (HiveOS) 驱动按双倍速率（Data Rate）计量；Windows 小飞机按物理基准时钟（Base Clock）计量。在 Windows 拉 +1000 实际物理频率正好等价于 Linux 的 +2000，算力 100% 完全一样，绝不会少算力。如果 Windows 硬拉 2000 则相当于超频 4000，会瞬间驱动崩溃黑屏。
